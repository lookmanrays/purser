# P1-03 contradiction: gate contract references undeclared artifacts.Store

## Conflict

The [gate contract](../../contracts/kernel/gate.yaml#L62-L90) specifies the Go interface for package `internal/kernel/gate`:

```go
type Tentative struct {
    Projection projection.Projection
    Revision   int64
    At         time.Time
    Binding    Binding
    Commitment string
    Artifacts  *artifacts.Store
}

type Options struct {
    Store     *store.Store
    Artifacts *artifacts.Store
    Clock     store.Clock
}
```

The Go compiler requires `artifacts.Store` to be declared in `internal/kernel/artifacts`. However:

1. `internal/kernel/artifacts` currently contains only `doc.go` and exports no types.
2. [contracts/kernel/artifacts.yaml](../../contracts/kernel/artifacts.yaml#L8) assigns ownership of package `internal/kernel/artifacts` to **P1-04** (`owner: P1-04`).
3. [P1-04 brief](P1-04.md) owns `scope.write: [internal/kernel/ops/work/**, internal/kernel/artifacts/**]` and depends on P1-03 (`depends_on: [P1-03]`).
4. [P1-03 brief](P1-03.md) depends only on P1-02a (`depends_on: [P1-02a]`), has `scope.write: [internal/kernel/gate/**]`, and lists `reuse: [internal/kernel/codec, internal/kernel/store, internal/kernel/projection]`.
5. Under [AGENTS.md](../../AGENTS.md) Rule 1, an agent must work only inside `scope.write`. [tools/briefcheck](../../tools/briefcheck/main.go#L339) rejects any stub or file written outside `scope.write` (`violation: path outside tests scope`).
6. Under [AGENTS.md](../../AGENTS.md) Rule 2, agents may never edit anything under `contracts/`.

Because `internal/kernel/artifacts` is unowned by P1-03 and outside its write scope, P1-03 cannot declare or stub `artifacts.Store`. Without `artifacts.Store` declared in `artifacts`, any stub or implementation of `contracts/kernel/gate.yaml` fails to compile (`undefined: artifacts.Store`). Consequently, package P1-03 cannot be stubbed, typechecked, or tested as written.

## Evidence

1. `internal/kernel/artifacts` has no Go declarations:
   ```sh
   $ ls internal/kernel/artifacts
   doc.go
   ```

2. When `internal/kernel/gate/zz_stub.go` is generated holding the exact declarations from `contracts/kernel/gate.yaml`, `go vet ./...` and `golangci-lint run` fail:
   ```text
   # github.com/lookmanrays/purser/internal/kernel/gate
   vet: internal/kernel/gate/zz_stub.go:61:24: undefined: artifacts.Store
   ```
   ```text
   internal/kernel/gate/zz_stub.go:61:24: undefined: artifacts.Store (typecheck)
   internal/kernel/gate/zz_stub.go:95:23: undefined: artifacts.Store (typecheck)
   ```

3. If P1-03 attempts to provide `internal/kernel/artifacts/zz_stub.go`, `make briefcheck ID=P1-03` rejects it:
   ```text
   violation: path outside tests scope: internal/kernel/artifacts/zz_stub.go
   ```

## Proposed resolution

Choose one of the following:

1. **(Recommended)** Declare a minimal type stub `type Store struct{}` in `internal/kernel/artifacts` on `main` (e.g. in `internal/kernel/artifacts/artifacts.go` or `internal/kernel/artifacts/zz_stub.go`). This satisfies Go typechecking for `gate` without altering any contract or package scope, and allows P1-04 to later implement `artifacts.Store` methods as planned.
2. Alternatively, update `contracts/kernel/gate.yaml` to decouple `gate` from `artifacts.Store` for M1 (e.g. using `any` or an unexported interface) until P1-04 introduces work operators.
3. Alternatively, add `internal/kernel/artifacts/**` to `scope.write` in `docs/packages/P1-03.md` so that P1-03 is permitted to create `internal/kernel/artifacts/zz_stub.go`.
