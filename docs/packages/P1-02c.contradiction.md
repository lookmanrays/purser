# P1-02c Contradiction Escalation

## 1. Contradiction: `briefcheck Scope` rejects `zz_stub.go` for packages with individual file paths in `scope.write`

### What is wrong

Package P1-02c introduces new Go declarations on `*store.Store`:
- `type TrustedHead struct { Revision int64; Hash string }`
- `func (s *Store) Verify(trusted *TrustedHead) error`
- `func (s *Store) Replay(trusted *TrustedHead) (Snapshot, error)`

Because these declarations do not exist in the ancestor package implementation (`internal/kernel/store` from P1-02a/P1-02b), the test author is required by `AGENTS.md` and `docs/agents/test-author.md` to add `zz_stub.go` to the package directory of `scope.write` so that the frozen tests can compile and `make red ID=P1-02c` can evaluate the stub failures.

However, `briefcheck Scope` rejects `internal/kernel/store/zz_stub.go` on branch `tests/P1-02c` with:
```
violation: path outside tests scope: internal/kernel/store/zz_stub.go
```
because `tools/briefcheck/main.go` line 339 checks whether the stub path itself matches `b.Scope.Write` patterns (`doublestar.Match(pat, p)`), rather than checking whether `p` resides in a package directory of `b.Scope.Write`.

Because `docs/packages/P1-02c.md` specifies individual files in `scope.write`:
```yaml
scope:
  write: [internal/kernel/store/replay.go, internal/kernel/store/verify.go]
```
rather than a directory glob like `internal/kernel/store/**`, `matchesAny("internal/kernel/store/zz_stub.go", b.Scope.Write)` returns `false`.

Consequently:
1. If `internal/kernel/store/zz_stub.go` is committed, `make briefcheck ID=P1-02c` fails `Scope`.
2. If `internal/kernel/store/zz_stub.go` is omitted, the test files `replay_test.go` and `verify_test.go` cannot compile (`undefined: TrustedHead`, `(*Store).Replay undefined`, `(*Store).Verify undefined`), causing `make red ID=P1-02c` to fail with `package failed to compile or build`.
3. If the stubs are placed inside `tests_frozen` (`replay_test.go`), they become frozen and cannot be deleted by the builder, conflicting with the builder's declarations in `replay.go` and `verify.go`.
4. The test author cannot modify `tools/briefcheck` (outside `scope.write`) or `docs/packages/P1-02c.md` (outside tests scope).

Package P1-02c cannot be tested as written.

### Evidence

1. `AGENTS.md` ("Branches and freezing", item 1):
   > "Tests: the brief's `test_author` opens a PR from `tests/<id>`, written from the contract and acceptance criteria only. It may also add `zz_stub.go` files in the package directories of `scope.write`, holding exactly the contract's Go declarations that do not exist yet, with bodies that `panic("unimplemented: <id>")`."

2. `docs/agents/test-author.md` section 3 ("Write"):
   > "- Write only paths matching `tests_frozen`, plus `zz_stub.go` files in the package directories of `scope.write`."

3. `tools/briefcheck/scope_test.go` line 154 documents this rule:
   > `// 2. zz_stub.go in scope.write pkg dirs: tools/p091/zz_stub.go`

4. But in `tools/briefcheck/main.go` lines 328-341:
   ```go
   isStub, isBriefDoc := filepath.Base(p) == "zz_stub.go", strings.HasPrefix(p, "docs/packages/"+id+".")
   if isBuild {
       ...
   } else if !isBriefDoc && !matchesAny(p, b.TestsFrozen) && (!isStub || !matchesAny(p, b.Scope.Write)) {
       violations = append(violations, "path outside tests scope: "+p)
   }
   ```
   For `p = "internal/kernel/store/zz_stub.go"` and `b.Scope.Write = ["internal/kernel/store/replay.go", "internal/kernel/store/verify.go"]`:
   - `isStub` is `true`, so `!isStub` is `false`.
   - `matchesAny(p, b.Scope.Write)` matches `internal/kernel/store/zz_stub.go` against `internal/kernel/store/replay.go` and `internal/kernel/store/verify.go`. Both return `false`.
   - `(!isStub || !matchesAny(p, b.Scope.Write))` evaluates to `false || true` = `true`.
   - `violations` appends `"path outside tests scope: internal/kernel/store/zz_stub.go"`.

5. Testing on `tests/P1-02c` confirms this:
   - Committing `zz_stub.go` produces:
     ```
     violation: path outside tests scope: internal/kernel/store/zz_stub.go
     exit status 1
     ```
   - Running without `zz_stub.go` produces:
     ```
     package failed to compile or build:
     # github.com/lookmanrays/purser/internal/kernel/store [github.com/lookmanrays/purser/internal/kernel/store.test]
     internal/kernel/store/replay_test.go:28:16: undefined: TrustedHead
     internal/kernel/store/replay_test.go:42:15: s.Replay undefined (type *Store has no field or method Replay)
     ...
     ```

### Proposed Fix

Fix `tools/briefcheck/main.go` so that a `zz_stub.go` file is recognized as valid when its directory matches the package directory of any path in `b.Scope.Write`:

```go
func inScopePackage(p string, scopePatterns []string) bool {
    pkgDir := filepath.Dir(p)
    for _, pat := range scopePatterns {
        if filepath.Dir(pat) == pkgDir {
            return true
        }
        if m, _ := doublestar.Match(filepath.Dir(pat), pkgDir); m {
            return true
        }
        if m, _ := doublestar.Match(pat, p); m {
            return true
        }
    }
    return false
}
```
And update line 339 in `tools/briefcheck/main.go`:
```go
} else if !isBriefDoc && !matchesAny(p, b.TestsFrozen) && (!isStub || !inScopePackage(p, b.Scope.Write)) {
    violations = append(violations, "path outside tests scope: "+p)
}
```

Alternatively, adjust `docs/packages/P1-02c.md` to include `zz_stub.go` or use the package glob:
`scope.write: [internal/kernel/store/replay.go, internal/kernel/store/verify.go, internal/kernel/store/zz_stub.go]`
or
`scope.write: [internal/kernel/store/**]`

Fixing `briefcheck` is recommended because other briefs also restrict `scope.write` to specific files (e.g. `P1-05` and `P1-08`).
