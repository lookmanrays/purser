# P0-01 Repository bootstrap

## Goal

An empty but fully wired Go repository: layout, build, lint with layer rules, CI, and purser-main kept as a runnable read-only reference.

## Context

Every later package relies on this skeleton and on CI enforcing it. See the plan's Ground rules and the design's Architecture section.

## Decision needed before start (you)

Done: purser-main lives in reference/python/, moved in the planning-batch commit. Do not move it again.

## Design

- `go.mod` with the chosen module path and the current stable Go version.
- Package directories from AGENTS.md, each with only a `doc.go` stating its purpose and layer.
- `Makefile` targets: `check` (build, vet, lint, `go test -race ./...`), `test`, `fuzz`, `bench`, `briefcheck` (runs `python3 tools/check_briefs.py` until P0-02 replaces it; CI installs PyYAML).
- `.golangci.yml` enables govet, staticcheck, errcheck, revive, gofmt, goimports and depguard. depguard encodes the layer rules below.
- CI on every pull request: Ubuntu, Go from `go.mod`, Git 2.45 or newer, `make check`, and `python3 reference/python/docs/contracts/check_vectors.py`.
- License Apache-2.0 with NOTICE.

Layer rules for depguard (a package may import only what its row lists, plus the standard library and allowed modules):

| Package | May import internal |
| --- | --- |
| `internal/kernel/codec` | nothing |
| `internal/kernel/projection` | codec |
| `internal/kernel/store` | codec, projection |
| `internal/kernel/artifacts` | codec |
| `internal/kernel/view` | codec, projection |
| `internal/kernel/impact` | codec, projection, view |
| `internal/kernel/gate` | codec, projection, store, artifacts, view, impact |
| `internal/kernel/ops/...` | codec, projection, gate, artifacts, view, impact |
| `internal/effects/...` | codec |
| `internal/graph/...` | other `internal/graph/...` only |
| `internal/cli` | anything under internal |
| `cmd/purser` | `internal/cli` |

Depguard enforces package edges only, so no edge in this table is limited to types. When a package needs only another package's types, those types move down to a lower layer instead; for example, operators return `codec.EventSpec` rather than importing the store.

Later layers (`internal/model`, `internal/plan`, `internal/run` and so on) are added to this table by the package that creates them, as a contract change.

## Out of scope

No Go logic beyond `doc.go` files and an empty `main` that prints the version. No tests are required because this package adds no behaviour.

## Test plan

None. The reviewer checks the ACs by running the commands.

## Acceptance criteria

- AC-1 `make check` passes on a clean clone.
- AC-2 A throwaway import of `internal/graph` from `internal/kernel/codec` makes `make check` fail with a depguard error.
- AC-3 CI runs `make check` and the Python reference checker on a pull request, and both pass.
- AC-4 `docs/design.md`, `docs/plan.md`, `AGENTS.md` and `docs/packages/` are present.
- AC-5 `go run ./cmd/purser --version` prints the module version.

## Definition of done

Standard Definition of done, except coverage, which does not apply yet.

## Escalate if

The reference checker fails after the move, or Git 2.45 is unavailable on the CI runner.
