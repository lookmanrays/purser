# P6-04 Progress and evidence reports

## Goal

Wave updates on the tam task, links to branches, commits and PRs, and the final evidence report or the exact blocking question.

## Context

Design: Tracker integration (Execution, Done or blocked).

## Design

- One comment per wave boundary: closed, running, blocked, budget used.
- Link commits and PRs through tam's linking tools.
- On done: post the evidence report from P4-07 and move to Done. On blocked: post the question and move to Blocked.

## Out of scope

Field metrics (P6-07).

## Test plan

Fake tam; a run with three waves; a blocked run.

## Acceptance criteria

- AC-1 Each wave boundary posts exactly one update.
- AC-2 Done posts the evidence report and moves the task to Done.
- AC-3 Blocked posts the question and moves the task to Blocked.

## Definition of done

Standard Definition of done.

## Escalate if

tam comment size limits truncate the evidence report.
