# P4-03a Observers: scope, build, tests

## Goal

Deterministic observers that produce kernel evidence for a candidate: the diff stays in scope, it builds and type-checks, and its tests plus selected regression tests pass.

## Context

Design: Verification. Observers run outside the worker, on the exact candidate, in a clean container, and record observations and verdicts through the gate as observer and verifier bindings.

## Design

- Scope: diff of the candidate against the base within the node's write scope; frozen files unchanged by digest.
- Build: `go build ./...` and `go vet`, or `tsc --noEmit`, for affected packages.
- Tests: the node's obligations, plus regression tests selected from `covered_by` edges of changed symbols.
- Each observer submits `observation.record` with witness bytes (logs) and `evidence.record` with pass, fail or inconclusive.

## Out of scope

Conformance, reuse, lint (P4-03b, P4-03c).

## Test plan

Fixture candidates: in scope and passing; out of scope; a type error; a failing regression test selected by coverage.

## Acceptance criteria

- AC-1 An in-scope, passing candidate gets pass verdicts from all three observers.
- AC-2 A write outside scope gets a fail verdict naming the path.
- AC-3 A failing regression test selected through `covered_by` gets a fail verdict naming the test.
- AC-4 Observations carry their logs as witness bytes with matching digests.

## Definition of done

Standard Definition of done.

## Escalate if

Regression selection misses tests that a full run catches on the fixtures.
