# P1-06 Impact and invalidation

## Goal

Pure functions that compute what a contradicted premise or a changed basis affects: which decisions reconsider, which work goes stale, and which closures must be settled again.

## Context

This is PSA's local re-planning. Spec: `decisions-v1.md`, Closure and explanation; the continuity overlay in `lifecycle-v1.json`.

## Design

- `Affected(projection, assumptionID)` follows incoming `depends_on` edges at every depth, crosses a decision only when the assumption is one of its declared triggers, removes duplicates, and returns sorted decision and work IDs.
- `Reopen(projection, changedIDs)` returns closed work and ancestors whose basis includes a changed fact.
- `Settle(projection, view)` recomputes parent coverage separately from the traversal and reports a satisfied commitment whose accepted outcome no longer qualifies.
- Read dependencies include the relation set itself, so an inserted edge counts as a change.
- No events: the package returns sets. Operators turn them into events.

## Out of scope

Operators (P1-07 calls `Affected` from `assumption.observe`).

## Test plan

Graphs with diamonds, cycles, deep chains, decisions with and without the trigger, and unaffected siblings from the continuity overlay.

## Acceptance criteria

- AC-1 The continuity overlay's invalidated assumption affects exactly the decision and work it names, and leaves the listed siblings untouched.
- AC-2 A contradiction outside a decision's triggers leaves that decision and its dependents unaffected.
- AC-3 Diamonds and cycles terminate, and each ID appears once.
- AC-4 `Reopen` includes every ancestor whose basis contains a changed fact, and nothing else.
- AC-5 `Settle` reports a satisfied commitment whose accepted digest no longer matches.

## Definition of done

Standard Definition of done.

## Escalate if

The overlay requires traversing outgoing edges.
