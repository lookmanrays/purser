# P0-06 contradiction: frozen tests assert fixture and source strings that contradict reference vectors

## What is wrong

The frozen tests in `internal/testvectors/ac2_wire_test.go` and `internal/testvectors/ac3_lifecycle_test.go` assert hardcoded expected strings for `w.Legacy.Source` and `lc.Fixture` that contradict the frozen reference vector files `wire-v1.json` and `lifecycle-v1.json`.

Specifically:
1. `TestAC2_WireTopLevelSections` in `ac2_wire_test.go:109` asserts `w.Legacy.Source == "purser-main/v0.1"`, whereas the reference vector `reference/python/docs/contracts/wire-v1.json` defines `"legacy": { "source": "synthetic first batch, CommitmentCreated event_version 0", ... }`.
2. `TestAC3_LifecycleSections` in `ac3_lifecycle_test.go:77` asserts `lc.Fixture == "M3-LIFECYCLE-TRACE-v1"`, whereas the reference vector `reference/python/docs/contracts/lifecycle-v1.json` defines `"fixture": "notification retries"`.

P0-06 AC-1 and the brief design require `purser-v1/wire-v1.json` and `purser-v1/lifecycle-v1.json` to be copied from `reference/python/docs/contracts/` unchanged and byte-identical. Unmarshaling those genuine vectors into `WireVector` and `LifecycleVector` faithfully yields the strings from the reference vectors. Fabricating or overriding those fields in `Wire()` or `Lifecycle()` would corrupt the data exposed by the loader and constitute a prohibited workaround of frozen tests.

1. `reference/python/docs/contracts/wire-v1.json` (line 350):
   ```json
   "legacy": {
     "source": "synthetic first batch, CommitmentCreated event_version 0",
   ```
2. `internal/testvectors/ac2_wire_test.go` (lines 108–110):
   ```go
   // 9. legacy
   if w.Legacy.Source != "purser-main/v0.1" {
   	t.Errorf("w.Legacy.Source = %q, want %q", w.Legacy.Source, "purser-main/v0.1")
   }
   ```
3. `reference/python/docs/contracts/lifecycle-v1.json` (lines 2–3):
   ```json
   "contract": "purser.kernel/v1",
   "fixture": "notification retries",
   ```
4. `internal/testvectors/ac3_lifecycle_test.go` (lines 76–78):
   ```go
   if lc.Fixture != "M3-LIFECYCLE-TRACE-v1" {
   	t.Errorf("lc.Fixture = %q, want %q", lc.Fixture, "M3-LIFECYCLE-TRACE-v1")
   }
   ```
5. `P0-06.md` AC-1: "The three frozen files are byte-identical to the reference copies, and the manifest proves it."
6. `TestAC1_FrozenFilesByteIdentical` passes only when `testdata/vectors/purser-v1/wire-v1.json` and `lifecycle-v1.json` are byte-identical to `reference/python/docs/contracts/wire-v1.json` and `lifecycle-v1.json`.

## Proposed fix

Update the test author's assertions in `internal/testvectors/ac2_wire_test.go` and `internal/testvectors/ac3_lifecycle_test.go` to match the actual reference vectors:
- In `ac2_wire_test.go`: expect `"synthetic first batch, CommitmentCreated event_version 0"`.
- In `ac3_lifecycle_test.go`: expect `"notification retries"`.

Re-freeze the tests under tag `frozen/P0-06`.
