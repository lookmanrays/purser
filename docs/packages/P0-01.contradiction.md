# P0-01 contradiction: type-only imports are outside depguard's enforcement model

## What is wrong

P0-01 is its own contract. Its Design requires depguard to enforce the layer table, which marks imports from kernel operators to `internal/kernel/store` and from effect adapters to `internal/kernel/gate` as types only. Depguard cannot enforce either qualifier, and the brief scopes Go code to package docs and the version entry point.

## Evidence

- [P0-01 Design and layer table](P0-01.md#design) assigns both restrictions to depguard.
- [The depguard analyzer](https://github.com/OpenPeeDeeP/depguard/blob/v2.2.1/depguard.go#L68-L89) selects rules from the importing filename and passes only the import path to `importAllowed`. The decision is identical whether the source declares a field of type `store.Entry` or calls `store.Open()`, using those names as hypothetical examples.
- AC-2 tests a forbidden package edge. That probe can validate path restrictions, but it cannot show that the two allowed edges restrict symbol usage. AC-1 and AC-3 could appear green while the required qualifiers were unenforced.

## Proposed fix

Amend P0-01 to make depguard responsible for package edges and assign type-only enforcement to a named follow-up package with an explicit owner. Require that follow-up to accept type references and reject value or function references on both edges before the affected packages add consumers. If type-only enforcement must ship in P0-01, expand the approved write scope, dependency allowance as needed, and acceptance criteria for a semantic analyzer.

## Verification at stop

The unchanged Python reference checker passed all three tests using Python 3.14. AC-4 passed. AC-1, AC-2, AC-3 and AC-5 were not run because this contradiction stops implementation.

## Resolution

Commit `7e0823d5e05db2d251e2f48325c416fe6afae860` on `main` updated the P0-01 layer table and kernel contracts so depguard enforces package edges with no type-only qualifiers. Operators return `codec.EventSpec` and no longer import `internal/kernel/store`, while effect adapters import only `internal/kernel/codec` among internal packages. The brief also now requires `make briefcheck` to run `python3 tools/check_briefs.py` with PyYAML installed in CI.
