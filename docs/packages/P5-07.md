# P5-07 Router learning

## Goal

Default starting tiers per contract kind adjusted from recorded outcomes, so kinds that local models pass reliably stay local and kinds that keep escalating start higher.

## Context

Design: Routing and the cost model (the router learns).

## Design

- From `Routing` and `Cost` records and leaf-bench results, compute per contract kind and tier: first-pass rate, mean attempts and cost per accepted leaf.
- Choose the lowest tier whose expected cost per accepted leaf (including escalation) is minimal, with a minimum sample size and hysteresis to avoid flapping.
- Changes are proposed as a configuration diff for you to approve, never applied silently.

## Out of scope

Prompt tuning.

## Test plan

Synthetic outcome histories with known optimal tiers; flapping cases; small samples.

## Acceptance criteria

- AC-1 Synthetic histories yield their known optimal tiers.
- AC-2 Below the minimum sample size, tiers do not change.
- AC-3 Alternating outcomes do not make tiers flap.
- AC-4 Changes appear as a proposed diff and are not applied without approval.

## Definition of done

Standard Definition of done.

## Escalate if

Cost per accepted leaf cannot be attributed per contract kind.
