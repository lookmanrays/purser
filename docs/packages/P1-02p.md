# P1-02p Projection: records and reducers

## Goal

The projection model and its pure reducer registry, which the store (P1-02a) applies inside each transaction.

## Context

Split from P1-02a, which bundled this package with the store and exceeded its budget. The tests were written and frozen with P1-02a and only renumbered here. Spec: `kernel-v1.md`, Projection.

## Design

- `internal/kernel/projection` holds Record, Edge, Receipt, State and Projection, sorted as the spec says, with `Empty`, `FromMap`, `Map`, `Checksum` and lookups by ID, kind, edge target and receipt.
- A Registry maps (event type, version) to a pure reducer and rejects unknown pairs with `unsupported_version`, leaving the projection as it was.
- `projection.Base()` registers the M1 events (`ProposalReceipted`, `CommitmentCreated` v0 and v1, `CommitmentEdited`, `ApprovalRequested`, `ApprovalResolved`, `CommitmentActivated`).

## Out of scope

Storage, transactions and the `CommitmentCreated` v0 upcast (P1-02a).

## Test plan

Load the wire snapshots and compare checksums, lookups and sort order. Register and apply unknown types and versions. Fold every golden log from the gate scenarios and the legacy upcast through `Base()`. The reducer parity fixture comes from the reference projector.

## Acceptance criteria

- AC-1 `FromMap` of `snapshot_at_4` and `snapshot_at_8` yields projections whose checksums equal the `projection_hash` recorded at those revisions, whose lookups return the snapshot's records and receipts, and whose lists keep the spec's sort order.
- AC-2 An unregistered event type or version fails with `unsupported_version`, and the projection stays as it was.
- AC-3 `Empty()` has no records, receipts or edges, its map form holds empty lists, and its checksum is the hash of that map.
- AC-4 Folding each golden log from `tests/test_gate.py` scenarios through `projection.Base()` reproduces every recorded snapshot.

## Definition of done

Standard Definition of done.

## Escalate if

A golden snapshot cannot be reproduced by a pure reducer.
