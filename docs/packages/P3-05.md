# P3-05 Validator: graph checks

## Goal

A deterministic program that decides whether a plan is done: checks 1 to 9, 11 and 12 of the design's definition of done for planning, with a machine-readable report.

## Context

Design: Definition of done for planning. Check 10 (the skeleton compiles and its tests fail) is P3-07.

## Design

Each check is a pure function over the bundle, the kernel snapshot and the graph store, returning findings with a check number, severity, subject IDs and a fix hint:

1. Every acceptance criterion maps to at least one acceptance test.
2. Every work node implements exactly one contract and has at least one test.
3. Every contract has one producer and at least one consumer or acceptance test; every data type it names exists.
4. The work graph is acyclic; every dependency points to a planned node or an existing graph symbol.
5. Leaves fit the leaf budget (diff lines, files, closed context).
6. Write scopes in the same wave do not overlap (waves computed as the scheduler would).
7. No new symbol duplicates one the reuse finder marks equivalent above the threshold.
8. Layer and dependency rules from module contracts hold for every planned edge.
9. Every unknown is settled by a decision or a time-boxed spike node.
11. Every UI component contract lists its states.
12. The cost estimate fits the task budget, or the bundle carries a budget request.

The report is canonical JSON with its digest, attached to the design the human approves.

## Out of scope

Check 10 (P3-07) and any model call.

## Test plan

One passing fixture bundle and at least one failing fixture per check.

## Acceptance criteria

- AC-1 The passing fixture produces no findings.
- AC-2 Each failing fixture produces exactly the finding for its check, with the right subjects.
- AC-3 The report digest is stable for equal inputs.
- AC-4 Waves used by check 6 match the scheduler's wave rule on the same input.

## Definition of done

Standard Definition of done.

## Escalate if

A check needs judgment rather than a deterministic rule.
