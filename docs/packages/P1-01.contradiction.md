# P1-01 builder escalation

P1-01 is marked ready and requires reuse of the P0-06 conformance loader. The loader and its vector tree are absent from both the frozen base and the delivery base. P1-01's write scope covers only `internal/kernel/codec/**`. Supplying the missing loader or rewiring the frozen tests would require changes owned by another package or role.

## Evidence

- The commands below each print no paths. The frozen tag resolves to `f66040e825bebca974147ef11f61cf397095b5f3`. The verified `origin/main` head was `335d770367a458070c3cfb51212fe7185e5e6eeb`.

  ```sh
  git ls-tree -r --name-only frozen/P1-01 -- internal/testvectors testdata/vectors
  git ls-tree -r --name-only origin/main -- internal/testvectors testdata/vectors
  ```

- The frozen `internal/kernel/codec/helpers_test.go` reads `reference/python/docs/contracts/wire-v1.json` directly and describes the P0-06 copy as a guarantee. The reference vectors are available. `PYTHONDONTWRITEBYTECODE=1 python3.14 reference/python/docs/contracts/check_vectors.py` passed all three reference checks.
- The brief allocates 200 changed lines across canonical encoding, strict decoding, typed errors, hashing, ID and time grammar, event envelopes, and chain verification. The readable Go sketch I sized was 293 lines. Even comparing it with the stub as if both used the same filename, it would add 228 and delete 33 lines. This is an estimate for that approach.

## Proposed split

1. Resolve the P0-06 prerequisite on `main` and have the test author freeze the intended fixture dependency. The package owner can also revise the brief to make the existing read-only reference fixtures the supported input for this package.
2. Give canonical encoding, strict decoding and the round-trip property their own implementation and frozen checks (AC-1, AC-3, AC-4 and AC-7).
3. Build the tagged hash, ID and UTC grammar, event envelope, and chain verifier on the codec API (AC-2, AC-5 and AC-6). Split and freeze the test sets through the test-author workflow.

This PR records the escalation. The Go implementation, race acceptance, coverage, and five-minute fuzz run are pending.
