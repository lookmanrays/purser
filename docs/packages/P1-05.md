# P1-05 Closure and work view

## Goal

Outcome bases and digests, closure eligibility with typed reasons, the q01 to q10 answers and the frontier, plus the `work.close` and `work.accept` operators.

## Context

Spec: `kernel-v1.md`, Evidence and the outcome-basis paragraph; `work-v1.md`, Outcomes and reads.

## Design

- `WorkView` is a pure function of a projection and an evaluation time.
- The basis keys are exactly `work, generation, candidate, coverage, children, witnesses, decisions, obligations, effects`, with sets sorted by ID, and `Outcome = H("outcome", basis)`.
- Leaf: a current candidate and at least one positive obligation, each with a qualifying verdict from the current run, or a waiver.
- Parent: declared coverage (`all`, `any` or `k_of_n`) over qualifying closed children, plus its own obligations.
- Fail, inconclusive or mixed verdicts block closure until a fresh run passes or a waiver applies.
- `work.close` rechecks eligibility in the gate transaction and returns `closure_blocked` with typed reasons when blocked. `work.accept` closes the root and satisfies the commitment for the exact current digest.

## Out of scope

Invalidation traversal (P1-06), which settles closures after premise changes.

## Test plan

Reproduce `outcome_vectors`. Build projections for each coverage kind, waivers, fail-then-pass, mixed verdicts and acceptance against a stale digest. Compare answers with `status_by_revision`.

## Acceptance criteria

- AC-1 Each basis in `outcome_vectors` hashes to its digest.
- AC-2 Answers at each revision listed in `expected.status_by_revision` equal the listed answers.
- AC-3 `all`, `any` and `k_of_n` select the specified witnesses: all, the first qualifying child ID, the first k IDs.
- AC-4 A fail or inconclusive verdict blocks closure until a fresh passing run or a matching waiver.
- AC-5 `work.close` on ineligible work returns `closure_blocked` with sorted, typed reasons.
- AC-6 `work.accept` with an outdated digest is rejected, and with the current digest closes the root and satisfies the commitment.

Standard Definition of done.

## Escalate if
