# P6-01 tam MCP client

## Goal

A typed client for tam's MCP server, connected with Purser's own agent identity and permissions.

## Context

Design: Tracker integration with tam. Open question: tam must confirm MCP access for a custom client before this package goes to ready.

## Design

- Connect with the MCP Go SDK using a token from the OS keychain or an environment variable, never from a config file in the repository.
- Typed wrappers for the tam tools Purser uses: list tasks, get task, change status, comment, link commit or PR, attach file.
- Tool discovery at connect time; a missing tool fails with `tam_tool_missing`.
- Rate limiting and retries on transient errors.

## Out of scope

Mapping and polling (P6-02).

## Test plan

A fake MCP server with recorded tam tool schemas and responses.

## Acceptance criteria

- AC-1 Each wrapper calls the right tool with validated arguments and parses the recorded response.
- AC-2 A missing tool fails with `tam_tool_missing`.
- AC-3 The token is never written to logs or artifacts.

## Definition of done

Standard Definition of done.

## Escalate if

tam has not confirmed custom-client access.
