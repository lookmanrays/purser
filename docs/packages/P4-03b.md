# P4-03b Observers: conformance, reuse

## Goal

Evidence that an implementation matches its contract (signatures, types, examples) and adds no duplicate of an existing symbol.

## Context

Design: Verification (Contract conformance, Reuse).

## Design

- Conformance: index the candidate, compare each implemented signature with the contract's declaration, and run the contract's examples as tests generated by P3-06.
- Reuse: new symbols in the candidate are queried with `FindLike`; a match above the threshold that is not in the node's `reuse` list fails, and a listed reuse symbol that is not called fails.

## Out of scope

Lint and architecture (P4-03c).

## Test plan

Fixtures: matching implementation; changed parameter type; failing example; a duplicated helper; a required reuse symbol not called.

## Acceptance criteria

- AC-1 A matching implementation gets pass verdicts.
- AC-2 A signature that differs from the contract fails with both signatures in the observation.
- AC-3 A failing contract example fails with the example's inputs.
- AC-4 A new symbol duplicating an existing one fails with the match and its score.
- AC-5 A listed reuse symbol that is never called fails.

## Definition of done

Standard Definition of done.

## Escalate if

Signature comparison needs type information that SCIP does not provide.
