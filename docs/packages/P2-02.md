# P2-02 SCIP ingestion

## Goal

Run `scip-go` and `scip-typescript` as external tools, decode their indexes, and load definitions, references, relationships, signatures and documentation into the graph store.

## Context

SCIP gives compiler-accurate symbols for Go and TypeScript without writing analyzers. The design names SCIP as the primary indexer, with syntax and language-server fallbacks.

## Design

- `Run(ctx, repo, lang)` locates the indexer on `PATH`, records its name and version, runs it in the repository with a timeout, and returns the path of the produced `index.scip`. A missing indexer returns `indexer_missing` naming the tool and an install hint.
- `Load(index, repo)` decodes the protobuf with the SCIP Go bindings and maps it to store batches, one per document:
  - each document becomes a `file:` node with its content SHA-256;
  - each definition occurrence becomes a `sym:` node with range, kind, display name, signature (from the symbol's signature documentation) and documentation;
  - package and module nodes come from the symbol descriptors;
  - `contains`, `defines`, `references` (with a count per pair), `implements` (from relationships) and `imports` edges;
  - local symbols (`local N`) are skipped.
- Exported is true for Go identifiers starting with an upper-case letter and for TypeScript symbols that are exported from their module.
- Indexer stderr is captured; on failure the previous graph stays untouched.

## Out of scope

Calls edges, which come from the language server where needed (P2-04). Incremental runs (P2-05).

## Test plan

Commit two small fixture repositories (Go and TypeScript) with their pre-generated `index.scip` files, so `Load` tests need no indexer. `Run` tests are skipped with a clear message when the indexer is missing, and run in CI where it is installed. Cover interfaces and implementations, re-exports in TypeScript, generics, methods and test functions.

## Acceptance criteria

- AC-1 Loading the Go fixture index produces the exact node and edge sets in its golden file.
- AC-2 Loading the TypeScript fixture index produces the exact node and edge sets in its golden file.
- AC-3 A Go type implementing an interface gets an `implements` edge to that interface.
- AC-4 Local symbols never appear as nodes.
- AC-5 A missing indexer fails with `indexer_missing` and leaves the store unchanged.
- AC-6 An indexer failure leaves the store unchanged and returns its stderr in the error details.
- AC-7 Snapshot metadata records each indexer's name and version.

## Definition of done

Standard Definition of done. CI installs `scip-go` and `scip-typescript` for the `Run` tests.

## Escalate if

An indexer's output lacks signatures or documentation for a common symbol kind.
