# P1-02a cannot add its required SQLite dependency within write scope

## Conflict

The [package brief](P1-02a.md) requires `modernc.org/sqlite` and lists it in `deps_allowed`. Its `scope.write` contains only `internal/kernel/store/**` and `internal/kernel/projection/**`. The [builder playbook](../agents/builder.md) and [AGENTS.md](../../AGENTS.md) require implementation edits to match `scope.write`. The mandatory driver is absent from the root module, so a clean checkout cannot build the SQLite store within the stated write scope.

## Evidence

- The driver is absent at both `frozen/P1-02a` (`f62ba0c`) and `origin/main` (`c9b2d39`).
- `go list -m -mod=readonly modernc.org/sqlite` exits 1 with `go: module modernc.org/sqlite: not a known dependency`.
- [The scope checker](../../tools/briefcheck/main.go#L331) already exempts root `go.mod` and `go.sum` on build branches with a nonempty `deps_allowed` list. The written builder rules omit that exception.

AC-1 through AC-7 require a buildable SQLite store. The builder playbook directs escalation before implementation when the brief conflicts with its required work.

## Proposed resolution

Explicitly add root `go.mod` and `go.sum` to the brief's `scope.write` for pinning the allowed SQLite driver and recording its required transitive dependencies. Keep the frozen tag and contract files as the implementation baseline. Then resume the build on `build/P1-02a`.
