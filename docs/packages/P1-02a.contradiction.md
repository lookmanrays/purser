# P1-02a contract check rejects a change already on main

## Conflict

P1-02a depends on the projection package split in #23 and the projection implementation in #25. The build must integrate `origin/main` and carry main's projection files. The build contract check compares every contract against the older `frozen/P1-02a` snapshot and treats changes already on main as changes made by this PR.

## Evidence

- The frozen tag `5780dd0` predates #23. That PR changed `contracts/kernel/projection.yaml` from `owner: P1-02a` to `owner: P1-02p`.
- `git diff --exit-code origin/main...HEAD -- contracts internal/kernel/projection` succeeds on the store candidate. Both frozen store tests also match the tag byte for byte.
- `make briefcheck ID=P1-02a` and `make briefcheck` pass validation, scope and frozen-file checks. Both fail with `contracts/ changed when contract_change is false: contracts/kernel/projection.yaml`.
- [The contract check](../../tools/briefcheck/main.go#L376) selects the frozen tag as the baseline whenever the branch starts with `build/`.

## Proposed resolution

Have briefcheck compare contract changes with main for build branches. Keep the frozen baseline for test byte identity and scope checks. An inherited change such as #23 should pass, and a contract change introduced by a build with `contract_change: false` should still fail.
