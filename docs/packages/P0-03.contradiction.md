# P0-03 Budget Escalation and Split Proposal

## What is wrong

`docs/packages/P0-03.md` sets `budget: {changed_lines: 600, excluding: tests}` across `scope.write: [contracts/records/**, internal/schema/**]`.

Implementing the full contract cleanly in one package exceeds the 600-line budget:
- `contracts/records/*.schema.json` requires 33 JSON Schema Draft 2020-12 files (`defs`, `proposal`, `binding`, `event` covering 33 event types, `receipt`, `record`, `snapshot`, `answers` covering `q01`–`q10`, `WorkSpec`, 16 v1 `fields.<Kind>` schemas, 5 v2 `fields.<Kind>` schemas, and 3 `graph.*` schemas), which total **671 lines** even with compact single-line-per-event/question formatting in `event.schema.json` (60 lines) and `answers.schema.json` (18 lines).
- `contracts/records/embed.go` (9 lines) + `internal/schema/schema.go` (191 lines) add **200 lines**.
- Total implementation size is **871 lines** (838 net changed lines after deleting the 33-line `internal/schema/zz_stub.go`), which is **271 lines (45%) over** the 600-line budget. Formatting `event.schema.json` and `answers.schema.json` with standard multi-line indentation for contract review and adding remaining reference-parity checks (`Decision` set-inclusion, sorted `git_paths`, `intent` OID distinctness/algorithm checks, and `binding` proof attachments) would raise the total above 1,100 lines.

Because `tools/briefcheck` caps `budget.changed_lines` at `600` for size `M` and `L` briefs (`tools/briefcheck/main.go#L85-L90`), the brief budget cannot simply be raised above 600 without either splitting the package or exempting `contracts/records/*.schema.json` from the code-line budget.

### Draft vs. recorded vector differences observed

Per `P0-03.md`, v1 field sets follow the recorded vectors and reference reducers rather than the draft summary comments in `contracts/records/records.draft.yaml`:
- `WorkItem`: omits `children` and omits `title` on root items; adds `result`, `closed_outcome`, `accepted_outcome`, `causes`, `structural_supports`, `effect_slots`.
- `Assignment`: adds required `state`; `work_supports` is optional.
- `Result`: adds `work`, `generation`, `producer`.
- `Obligation`: adds `current_run`, `waiver`.
- `Evidence`: adds `verifier`.
- `Waiver`: adds `work`, `generation`, `candidate`, `principal`.
- `Assumption`: adds `causes` and optional `impact_edges`.
- `Decision`: adds `effective_revision`, `causes`, and optional `superseded_by`.
- `DecisionOpinion`: fields are `decision`, `opinion`, `author` (no `stance` or `rationale`).
- `Effect`: stores `repository`, `resource`, `paths` on `WorkItem.fields.effect_slots`; stores `work`, `slot`, `state` plus lifecycle fields (`intent`, `intent_digest`, `repository_instance`, `changed_paths`, `superseded_by`, `attempt`, `observation`, `reason`) on `Effect`.
- `AuthorityGrant`: adds `repository`, `repository_instance`, `resource`, `paths`, `principal`, `capability`, and optional `in_flight_at_revocation`.
- `EffectAttempt`: adds `broker`, `authorized_at`, `grant`, `repository`, `repository_instance`, `resource`, `work`, and optional `observation`, `reason`.
- `ProposalReceipted` / `receipt` `details`: `state` also includes `superseded` (from redelivering `effect.request` after an effect is superseded).

All recorded vectors and golden logs validate with `additionalProperties: false`.

## Proposed fix

- **Option 1 (Recommended — split into two briefs, matching P0-07/P0-07b and P1-02a/P1-02p)**:
  1. **`P0-03` (Core validator, wire envelopes, answers, v2 & graph schemas — budget 600)**:
     Owns `internal/schema/schema.go`, `contracts/records/embed.go`, `defs.schema.json`, `proposal.schema.json`, `binding.schema.json`, `receipt.schema.json`, `record.schema.json`, `snapshot.schema.json`, `answers.schema.json`, `WorkSpec.schema.json`, the 5 v2 `fields.<Kind>.schema.json` files, and `graph.{node,edge,meta}.schema.json` (~548 lines total, within 600). Keeps `TestAC3_`–`TestAC7_` and the non-event/non-v1-fields parts of `TestAC1_` (renumbered as needed).
  2. **`P0-03b` (v1 event and record-kind schemas — budget 550)**:
     Depends on `P0-03`; owns `contracts/records/event.schema.json` and the 16 v1 `fields.<Kind>.schema.json` files (~333 lines compact, ~500 lines standard multi-line formatted). Owns `TestAC1_GoldenEvents`, the `events`/`legacy_events` subtests of `TestAC1_WireExamples`, and `TestAC2_WireAndGoldenRecords` (renumbered `TestAC1_`/`TestAC2_` on `tests/P0-03b`).
- **Option 2 (Alternative — exclude declarative JSON schemas from code-line budget)**:
  Exempt `contracts/records/*.schema.json` (like `go.mod` and `go.sum`) from `P0-03`'s 600-line code budget; the Go implementation (`contracts/records/embed.go` + `internal/schema/schema.go`) is 200 lines.
