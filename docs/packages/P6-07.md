# P6-07 Field log

## Goal

Per-task metrics for every real task, plus bypasses (tasks done outside Purser) and their reasons.

## Context

Design: Evaluation ("The field log decides"). P6 gate: one week of real tasks with every bypass logged.

## Design

- Per task: level, accepted, false done, out-of-scope edits, duplicates, layer violations, tokens and price by role, human minutes, wall-clock, rework after acceptance.
- Bypass entries: `purser fieldlog bypass <tam-id> --reason` or a tam label; weekly summary.
- Export as JSON and CSV.

## Out of scope

Dashboards (later UI).

## Test plan

Fixture kernel history with three tasks and one bypass.

## Acceptance criteria

- AC-1 Each completed task has all listed metrics.
- AC-2 Bypasses are recorded with reasons and appear in the weekly summary.
- AC-3 Exports match their golden files.

## Definition of done

Standard Definition of done.

## Escalate if

A metric cannot be derived from kernel records.
