# P1-08a Effect operators

## Goal

The kernel side of governed Git effects: slots, grants, intents, authorization cutoffs and reconciliation, with exactly the digests purser-main froze.

## Context

Spec: `effects-v1.md` and the external-effect paragraphs of `kernel-v1.md`.

## Design

- Operators: `effect.require`, `grant.request`, `grant.revoke`, `effect.request`, `effect.authorize` and `effect.reconcile`, with the fields and callers in the spec. `approval.answer` from P1-03 issues grants.
- `IntentDigest(intent) = H("effect", intent)`; the receipt ref is `refs/purser/receipts/<digest>`.
- Trusted attachments `git_preparation` and `git_observation` come only from the launcher binding, with exactly the listed keys.
- Overlapping unresolved dispatches to the same ref are excluded, including across reassignment.
- Expiry is exclusive. An earlier revocation prevents authorization; a later one records in-flight attempts.
- `Redelivery(binding, proposal)` returns an earlier exact receipt or none, checking the historical role and assignment scope.
- The package registers reducers for every effect event in the reference kernel.

## Out of scope

Running Git (P1-08b). The gate transaction never runs Git.

## Test plan

`immutable_effect`, `alternative_cutoff_orders`, `alternative_recovery`, revocation before and after authorization, expiry equality, an overlapping dispatch and redelivery after a lost acknowledgment.

## Acceptance criteria

- AC-1 `IntentDigest` of the trace's intent equals `intent_digest`, and the receipt ref equals `protected_receipt_ref`.
- AC-2 Each order in `alternative_cutoff_orders` yields the specified dispatch state and transition count.
- AC-3 Each case in `alternative_recovery` reconciles to the specified state.
- AC-4 Authorization at exactly the grant's expiry is refused.
- AC-5 A second live dispatch to the same ref is excluded while the first is unresolved.
- AC-6 `Redelivery` returns the earlier receipt for an exact retry and none for a new request.
- AC-7 An attachment with missing or extra keys is rejected.
- AC-8 Folding each golden log from `tests/test_effects.py` through the registered reducers reproduces every recorded snapshot.

## Definition of done

Standard Definition of done.

## Escalate if

Reconciliation needs Git facts not present in `git_observation`.
