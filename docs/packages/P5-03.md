# P5-03 Local models

## Goal

Local models on your RTX 5070 Ti served through Ollama or llama.cpp, with health, throughput and GPU-slot limits visible in `purser models`.

## Context

Design: Open-source foundation (local models to benchmark first on 16 GB).

## Design

- Detect configured local endpoints; health check with a tiny prompt; measure tokens per second.
- GPU slots: a configurable concurrency limit per endpoint, used by the scheduler.
- `purser models` lists providers, tiers, models, health, throughput and slot use.
- The Windows host runs the model server; Purser in WSL2 reaches it over the host address.

## Out of scope

Choosing which local model is best (the leaf bench, P5-05).

## Test plan

Fake OpenAI-compatible servers: healthy, slow, down.

## Acceptance criteria

- AC-1 A healthy endpoint is listed with measured throughput.
- AC-2 A down endpoint is listed as unhealthy and its tier is skipped by routing.
- AC-3 Concurrent requests never exceed the slot limit.

## Definition of done

Standard Definition of done.

## Escalate if

WSL2 cannot reach the Windows-hosted server reliably.
