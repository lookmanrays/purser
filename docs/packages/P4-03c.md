# P4-03c Observers: lint and architecture

## Goal

Lint and layer rules as evidence: golangci-lint with depguard for Go, eslint and dependency-cruiser for TypeScript, with layer rules derived from module contracts.

## Context

Design: Verification (Lint and architecture).

## Design

- Generate depguard and dependency-cruiser rule files from module contracts' `allowed_imports`.
- Run the linters in the sandbox on affected packages; parse their JSON output into findings.
- Verdict fail on any error-level finding; warnings are recorded but do not fail.

## Out of scope

Formatting fixes.

## Test plan

Fixtures with a layer violation in Go and in TypeScript, a lint error, and clean code.

## Acceptance criteria

- AC-1 Clean fixtures pass.
- AC-2 A Go import outside `allowed_imports` fails with the import and rule.
- AC-3 A TypeScript import outside `allowed_imports` fails with the import and rule.
- AC-4 Lint warnings are recorded without failing the verdict.

## Definition of done

Standard Definition of done.

## Escalate if

Module contracts cannot express a needed layer rule.
