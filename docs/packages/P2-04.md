# P2-04 Language-server client

## Goal

A small, reliable client for `gopls` and `typescript-language-server` that answers definitions, references, hover signatures, workspace symbols and rename previews.

## Context

Observers and the reuse finder need precise answers for code that changed after the last full index. Rename previews let the planner see the blast radius of a contract change.

## Design

- JSON-RPC 2.0 over stdio with `Content-Length` framing. One server process per language and workspace, started lazily and shut down with `shutdown` and `exit`.
- Hand-written LSP types for only the methods used: `initialize`, `initialized`, `textDocument/didOpen`, `textDocument/definition`, `textDocument/references`, `textDocument/hover`, `textDocument/prepareRename`, `textDocument/rename` and `workspace/symbol`.
- `Rename` returns the edit set without applying it.
- Requests have per-call timeouts; a crashed server restarts once, then the call fails with `server_crashed`.
- Positions are converted between LSP UTF-16 columns and the store's byte columns.

## Out of scope

Diagnostics streaming, completion and code actions.

## Test plan

A fake server in tests that replays recorded LSP exchanges, so CI needs no real server. Integration tests against real `gopls` and `typescript-language-server` run when installed. Cover UTF-16 conversion with non-ASCII lines, a crash and restart, and a timeout.

## Acceptance criteria

- AC-1 Each method returns the result recorded in its fixture exchange.
- AC-2 UTF-16 columns convert to byte columns correctly on lines with multi-byte characters.
- AC-3 `Rename` returns edits and never writes a file.
- AC-4 A server crash triggers one restart; a second crash returns `server_crashed`.
- AC-5 A call exceeding its timeout returns `timeout` and leaves the client usable.
- AC-6 `Close` shuts the server down cleanly within two seconds.

## Definition of done

Standard Definition of done.

## Escalate if

A server needs workspace configuration that cannot be derived from the repository.
