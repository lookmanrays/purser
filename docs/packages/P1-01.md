# P1-01 Event codec and hash chain

## Goal

Canonical JSON bytes and `H(tag, x)` hashes that match purser-main bit for bit, plus strict decoding, ID and time validation, and chain verification.

## Context

The codec needs nothing from other Purser packages. Its frozen tests read purser-main's vectors from `reference/python/docs/contracts/` with the standard library, so `internal/testvectors` (P0-06) is not required. For the P1-01 bake-off, Claude wrote the frozen tests and both Codex and Antigravity build from `frozen/P1-01`.

Every digest in the kernel depends on this package: proposals, events, projections, outcomes and effects. Spec: `kernel-v1.md`, section Canonical bytes and hashes.

## Design

- A custom encoder, not `encoding/json`. Go's default escapes `<`, `>`, `&`, U+2028 and U+2029, which Python's `json.dumps(ensure_ascii=False)` does not.
- Escaping must match Python exactly: `\"`, `\\`, `\n`, `\r`, `\t`, `\b`, `\f`; any other character below U+0020 as `\u00xx` in lowercase hex; everything else, including DEL and non-ASCII, raw UTF-8.
- Object keys are sorted by Unicode code point. For valid UTF-8, byte order equals code point order.
- The strict decoder rejects duplicate keys, non-integers, integers outside ±(2^53−1), invalid UTF-8 and escaped lone surrogates.
- `Hash(tag, v)` computes `lowercase_hex(SHA256("purser/" + tag + "/v1" || 0x00 || C(v)))`.
- `VerifyChain` checks hashes, contiguous revisions, batch fields and `prev_hash` links. It returns the first bad revision.

## Out of scope

No storage, projection or event semantics.

## Test plan

Use `encoding_vector`, the `events` and `request_digests` sections of `wire-v1.json` and the legacy events. Fuzz `Decode` and `Encode` round trips. Write negatives for each rejection rule, and table tests for every escape class, including U+2028, `<` and DEL.

## Acceptance criteria

- AC-1 `Encode` of the encoding vector equals `canonical_utf8` byte for byte, and its SHA-256 matches.
- AC-2 `Hash("event", event_without_hash)` reproduces the `hash` of every event in `wire-v1.json`, and `Hash("proposal", …)` reproduces every request digest.
- AC-3 The decoder rejects duplicate keys, floats, out-of-range integers, invalid UTF-8 and lone surrogates, each with its own error code.
- AC-4 `<`, `>`, `&`, U+2028, U+2029 and DEL encode raw; control characters encode as lowercase `\u00xx`.
- AC-5 `VerifyChain` accepts the wire chain and returns the exact revision of a corrupted hash, a gap or a wrong batch field.
- AC-6 `FormatTime` and `ParseTime` accept only `YYYY-MM-DDTHH:MM:SS.ffffffZ` with valid Gregorian dates.
- AC-7 A fuzz target finds no input where `Decode(Encode(x))` differs from `x`.

## Definition of done

Standard Definition of done.

## Escalate if

Any vector cannot be reproduced exactly. Do not adjust the vector.
