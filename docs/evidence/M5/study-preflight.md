## Worker interface

All participants accept `run_case(directory, assets, freeze, arm, track, seed, rank, *, decide, progress=None, ...)` and `recover_case(directory, assets, freeze, arm, track, seed, rank, *, progress=None, ...)`. Recovery accepts the last persisted progress dictionary. Both return an M0 raw record. The collector binds `decide(prompt, *, deadline)` to the registration, unit and session and retains the original transport trace in `session.json`. For E1 and E2, the common model artifact is that trace, and the coding participant receives the isolated observer and snapshot constructor. E3 supplies its own model artifact, gets the registration digest and population, reads original adapter bytes through `read_record`, and accepts surviving records by ordinal during recovery. The cold readers return steps, active elapsed or its lower bound, outcomes and separate clean/stress observations. The collector and report use the existing Artifacts, FileArchive and Objects interfaces. The command examples and evidence layout are in [the study guide](../../../experiments/model_study/README.md).
