## Worker interface

All participants accept `run_case(directory, assets, freeze, arm, track, seed, rank, *, decide, progress=None)` and `recover_case(directory, assets, freeze, arm, track, seed, rank, *, progress=None)`. Recovery accepts the last persisted progress dictionary. Both return an M0 raw record. The collector binds `decide(prompt, *, deadline)` to the one registration/unit/session, archives original transport evidence, and installs `raw["artifacts"]["model"]` and model usage. A case journal links consequential public actions to the turn by its one-based number or retained original response. `reconstruct_case(raw, archive)` returns reconstructed facts including steps, active elapsed or its lower bound, experiment outcome fields and clean/stress observations. The collector/report read the M0 artifacts via the existing Artifacts, FileArchive and Objects interfaces. E3 uses experiments.model_e3 and owns the common E1 model-mode timer change.
