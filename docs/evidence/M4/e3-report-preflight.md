- The original `experiments/manifests/v1` defines the fixtures, prepared commit, schedule, budget, wire format and scientific predicates. The independent M4 observer provides 13 individual controls and nine aggregate controls. Their hand-scored outputs serve as test expectations.

The protected process transcripts identify the actual writer, its release and its termination or continued ability to publish. The participant's returned reconciliation and published decision establish its knowledge. A Purser gate observation is also bound to the hash-checked original kernel history and the bytes of its committed artifact. A final-looking branch, rewritten result row, timeout or detached status label cannot establish the original action.
- The writer captures public invocation and result, decision originals, native snapshots and process history. The reporter folds these sources, retaining the original occurrence and subsequent attempts. It checks physical scope, prior-writer quiescence, relative order of delivery, declaration, fresh authorization and publication, including refused calls. The participant exit and release clocks bound completion and cost. The case score, comparison tables and the verification command are the first consumers.
- The reporter reuses E1's strict JSON parser, content-addressed artifacts, Git pack restoration, raw schema validator and original kernel history reader. It owns only E3 evidence interpretation and aggregation. It leaves the emitter, runtime, schema and historical experiments with their existing owners. Filesystem reads of the archived original instance use captured bytes. Any Git reconstruction uses a temporary bare repository.
