## Design decision and operating feasibility

A lost acknowledgment, revoked grant, changed assignment or replaced intent must leave the original dispatch available for independent reconciliation. A matching confirmed effect consumes the logical operation. A confirmed absence permits a freshly authorized distinct attempt under current authority.

## Placement and impact

- Domain authority remains the gate. Scope comes from the current commitment, work, named assignment and its grantee, declared work slot, exact repository instance and logical ID, canonical branch, path allowlist, grant and expiry. Immutable intent retains precisely M0's keys. The slot links its current logical effect, including before a result exists. Grant/assignment policy is applied to independently measured changed paths. No proposal-supplied path list constitutes Git evidence.
- Human authority uses the existing ApprovalRequested / ApprovalResolved cycle, pending-origin and answer receipts and trusted local OS principal. A grant can name the current or a specific next assignment. A request from an executor remains inside that executor's current assignment. Grant revocation uses the authenticated principal and records the in-flight attempts in the serialized write. Revocation and post-cutoff reconciliation must remain possible when work is stale, replaced or expired.
- SQLite owns logical intent admission, same-slot binding, same-repository/ref unresolved exclusion, one distinct attempt per cutoff and idempotent original receipts. It reads current grant, work, dependencies, assignment, slot membership and exclusion facts. The broker freshly measures exact immutable Git objects while holding its repository guard, receives a release only for a newly committed cutoff, then performs its guarded Git CAS. Replaying an admission cannot mint another release. Raw transport IDs cannot change semantic identity.
- A separately bound Git observer compares intent, attempt, repository instance and actual Git witness. The gate verifies subject and classification consistency and retains the exact source report using the existing artifact store. Positive happened/absent observations and pending observations each leave an explainable durable record. Unknown writer, unreadable or inconsistent observations stay actionable. Historical settlements may be retained after reassignment but only the current required work and candidate may close.
- The sole event reducer rebuilds the new records and slot references. WorkView and the current support graph own the closure basis, descendants, current supports and Frontier. q05 uses caller-specified query time or the trusted clock, q06 lists outstanding attempts across all work states. ContextPack attenuates capabilities to its current assignment. Older binaries fail closed on new event types under the existing version contract. The M1–M5 profile trusts local ingress and the operator.
- Git path measurement, physical repository and protected ref identity, the real broker lease, Git child quiescence and history inspection belong to M4-B. Process wiring, actual external transition counts, independent continuity goldens and study registration belong to M4-C/G. The M4-A production module boundary is authority plus projection, with no Git subprocess or repository-write dependency.
