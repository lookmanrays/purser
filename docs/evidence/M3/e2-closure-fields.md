# E2 closure fields before collection

The original E2 protocol counts a temporary reopening and grades a publicly closed candidate on the revised retry behavior at the time of that closure. The independent estimator and hand cases were sealed before the implementation. Its procedure preserves each actual reopening and the distinct names, and checks W2 and its parent on their own declared Git candidates. These definitions apply to the original report, the three arms and the separately labeled controls. [M0 protocol](../../../experiments/manifests/v1/protocol.md) · [Frozen independent inventory](observer/frozen-m3-reference.json)

| Field | Meaning on an eligible intervention |
| --- | --- |
| `unaffected_reopened` | Count publicly observable closed-to-open transitions of W1 and W3, including a second reopening of the same item. Report the distinct sibling IDs separately. A duplicate reading of the same publication adds zero. A partial history can supply a lower bound. |
| `unaffected_both_retained` | A single observed interruption of either sibling disproves continuous retention. A positive conclusion requires complete coverage from delivery through the witnessed end. |
| `affected_invalid_closure` | An actual closure that asserts the changed retry requirement and whose exact candidate fails it counts. W2 and the notification parent can each make that assertion. Retain the subject, candidate, publication identity and protected verdict separately. A rejected close has no closure transition. A later correction preserves the earlier observation. In the closed-affected stress track, indicate whether a stale closure was visible at delivery and whether a new incorrect closure occurred. |

On the private plain-loop controls for `0ad579f`, W3 reopened twice. The candidate recorded one distinct sibling where the public raw transition count was two. In another trace W2 closed correctly on `a5cd7df`, then its parent closed on `7df4a199`, which failed revised W2. The reporter missed that actual parent declaration. A refused parent closure in the third control produced zero incorrect closures. These controls concern measurement. The primary comparison still uses the original 20 seeds, continuous two-sibling retention, summed rework and the all-obligations final pass count.
