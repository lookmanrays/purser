The first scripted implementation/signature used product and harness commit `70097e0a2b933713d4fe91e6eddb5c2132951f89`, frozen at `4f17401df47e0621b87aa3cac660335d50340e22`. The 60 primary cases and three controls completed on that implementation. The original archive and report are to be kept under their original registration.

The independent audit by the kernel worker, who did not author the scorer, found failures of measurement and case accounting. These are first findings on the original experimental implementation. Neither cluster has used a Reset. The development session has used one Reset for the unrelated M1 retained-history cluster.

The original 63 attempts completed, and checking their actual first nonempty self-review responses found no labels different from their recorded closure diagnoses.

**Remediation preflight.** Retain the frozen study rules and original series. The evaluation worker owns exact observations, evidence verification, diagnosis chronology and summaries in the probe, scorer and reporter. The orchestrator owns case setup/teardown, journal capture, recovery and durable marking of started cases in the run and suite controller. Use the same local host and offline Git fixtures. Each closed candidate is measured against its actual retained bytes. Probe infrastructure failures, candidate behavior, invalid timing types, incomplete work and verified negative outcomes must have distinguishable evidence. Capture actual published state at a cutoff, even when an action did not acknowledge. Preserve recorded actions on interrupted collection and qualify comparisons using eligible observations. Capture partial evidence when available, explicitly identify unavailable measurements and never repeat a started subject to improve the outcome. A separate archive and precollection pin establish the corrected replication. Exercise each failure class with a controlled real candidate or interrupted disposable case before collection, then commission an independent verification.
