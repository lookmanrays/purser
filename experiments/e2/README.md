# Scripted E2

Use the joined M3 source, the local Git fixture, Python 3.11+ and SQLite. The official schedule has 60 primary units, three clean units under the old schedule, and three already-closed affected stress units. It consumes zero model calls.

Run `python -B -m experiments.e2 freeze DIRECTORY` from a clean checkout. Commit its standalone `freeze.json` before `python -B -m experiments.e2 collect DIRECTORY`. The collector verifies the registration, checks the source bytes, takes a directory writer lock and never starts an existing participant again. Interrupted work is read from its preserved store and the sealed candidates. Private repetitions use `--replicate N --reason TEXT` and separate directories.

The frozen plan file and the Purser assignment both expose the current retry choice. All arms receive the same observation at the same work checkpoint. Each can identify W2 without reopening its siblings. The two verifier-equipped arms additionally receive identical public fixed-probe observations. The protected scorer uses separate seeded inputs and the actual queue. Version 1 is the old linear timing; version 2 grades the exponential W2 timing and composition. The unaffected criteria retain version 1. The public verifier has one decision-parameterized definition.

In a directory containing only `raw.zip`, run `python -B -m experiments.e2 report DIRECTORY` for Markdown and `python -B -m experiments.e2 verify DIRECTORY` for strict Git replay. Use a checkout containing the registered source bytes. Each raw row refers to an ordered journal, archived Git candidates and a platform artifact. The latter points to the participant trace. Purser traces carry the original event byte strings and a map from evidence SHA-256 to archived bytes. Each action and the incoming fault has public before/after snapshots. Exit Git evidence includes the actual HEAD and porcelain status bytes after the participant stops.

Score the original and diagnostic comparator separately. Count every attempted registered work action after the validated input through a witnessed cutoff. Sibling reopening or a bad closure once witnessed survives later repair. Stress records a stale closure visible on receipt separately from a new bad closure. Partial records expose independently observed facts, raw cost lower bounds and unavailable comparisons. A contradictory clock or exit cannot qualify paired costs or healthy clean overhead. Clean overhead requires two healthy, observed exits.
